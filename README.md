# lift-inspection-review

电梯年检不合格项复核工作台，服务南京景诚特种设备检测团队。应用把电梯档案、逐项检验、整改通知、复检证据和合格证签发串成一条可审计流程。

## 业务范围

- 操作员录入设备与检验项，失败项生成整改通知并预约复检。
- 主管审核复检结果并签发合格证，安全回路与制动器关键项一票否决。
- 复检证据必须使用原检验项编码，照片错配会被后端拒绝。
- worker 使用 `DecisionTreeClassifier(random_state=1066, max_depth=3)` 计算分流结果并导出规则路径。

## 业务核验模块

登录后打开页面右下角的「业务核验」。可从实时业务台账筛选记录、导出所选结果，主管可对当前证据签认并填写说明。

- **年检到期排程** 按年检到期日排序并标出近 30 天到期与逾期资产，供检验员安排路线。
- **关键项整改督办** 聚合关键不合格项及整改资料，未开单、过期或缺复检记录可分别交接。
- **证书有效性对照** 对照证书有效期与资产仍未验证的关键缺陷，保留主管判断依据。

### 二次扩展核验

- **复检影像归属核验** 把复检照片与原不合格项编号逐一对照，识别缺影像和串项证据。
- **复检员同档排班冲突** 按复检员与相同预约时点核对尚未完成的排班，重约或关闭后自动释放冲突。

## 业务处置与验收

登录后打开「复检补证与改约」。操作员提交结果、凭证号和说明，主管可复核关闭或退回补证，观察员可查看记录。关闭时复查源业务状态，处置历史保留每次操作。

- 串项影像补证验收
- 同档复检改约验收

## 离线分流规则包复核

登录后打开右下角「离线分流复核」。规则包把固定分流树（版本 `triage-tree-2026-11`，深度 3、4 个可达叶）连同分界值、两侧分支、每叶见证输入与 sha256 校验值打成自包含 JSON，断网也能在浏览器本地算出建议与命中分支。

- **发放与下载**：主管生成固定包，工作台可下载已发的包；包内容被 `content_hash` 钉住，下载时再次校验，被篡改的包禁止下载。
- **认领与续跑**：操作员以离线复核点名称认领，同一复核点重试只返回原认领凭据，不会重复发包。逐叶核对的进度写入检查点，中断后凭原凭据续跑，重试覆盖同一行而不是新增。
- **断网核对**：树遍历完全在浏览器执行（`triage-workbench.js` 内的本地引擎，与后端 `src/triage_tree.py` 有 Node 对拍测试）。离线保存与送审进入本地外发箱，联网后按队列幂等补传，重复提交不会产生第二个送审事件。
- **送审闸门**：固定包的每个可达叶、每个分界节点（分界值及左右分支）都核完才允许送审，漏算直接以 `CHECK_INCOMPLETE` 拦截。
- **逐项复核与退回**：服务端用包内同一棵固定树重放每个叶的输入，逐一核对可达叶、分界值、两侧建议与分支；漏算或不一致即退回，退回明细包含对不上的输入、期望值与实际值。主管也可手动退回并写明原因。
- **并发隔离**：两份包由不同复核点并发核对时各自维护检查点与进度；一份退回只影响该认领，其他已发包及其认领不受影响。被退回的复核点在同一认领记录上修正后可重新送审。
